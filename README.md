# tallyqueue

Tally config/queue key checks for twelve-factor services.

**Site:** https://theworker02.github.io/tallyqueue/

## Install / run

```bash
git clone https://github.com/theworker02/tallyqueue.git
cd tallyqueue
node src/cli.js
node --test
```
